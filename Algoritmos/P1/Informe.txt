# INTRODUCCIÓN

En está practica implementaremos y mediremos el tiempo de ejecución de 3
algoritmos distintos de la sucesión de Fibonacci:

~fib1: Algoritmo para el calculo de un numero en de la sucesión de Fibonacci
       empleando recursividad. Complejidad O(2^n)

~fib2: Algoritmo para el calculo de un numero en de la sucesión de Fibonacci
       empleando un bucle iterativo con dos variables (i,j). Complejidad O(n)

~fib3: Algoritmo para el calculo de un numero en de la sucesión de Fibonacci
       empleando entidades matemáticas, el bucle principal toma dos posibles
       caminos en funcion de si el numero es par o impar. Complejidad O(log(n))

El objetivo es verificar empíricamente las cotas ajustadas g(n) mediante la
comparación con una cota subestimada f(n) y una cota sobreestimada h(n) para
cada algoritmo.

# ENTORNO DE EJECUCIÓN

# CARACTERÍSTICAS DE LA MEDICIÓN

La unidad de tiempo empleadad para las mediciones es el microsegundo (μs).

Para tiempos inferiores al umbral de confianza seleccionado
( 1000 microsegundos / 1ms ), se repetirá la ejecución del algoritmo K = 1000
veces mediante un bucle, posteriormente se calculará el tiempo medio de
ejecución dividiento el tiempo total entre K

Si una medición ha sido obtenida mediante este método será indicado
en la tabla con un '*'

Además, para fib2 y fib3, en cada operación del algoritmo aplicamos
el módulo 2³¹ para evitar sobrepasar los 32bits de los enteros
y mantener la complejidad de las operaciones básicas

# OBSERVACIONES Y CONCLUSIÓN

En los tres casos, únicamente la cota propuesta g(n) hizo converger t(n)/g(n) hacia
una constante positiva  C > 0.
Mientras que la cota subestimada f(n) diverge a infinito
y la sobreestimada h(n) tiende a 0 en todas las mediciones

El algoritmo fib1 es el menos eficiente, con una complejidad de O(phi^n).
Para valores superiores a 32 el tiempo empieza a subir rápidamente

Le sigue fib2 que con una complejidad de O(n) permite calcular números
hasta 10⁷.
Sin embargo, a partir de esa cifra comienza a tardar segundos en ejecutarse.

Fib3 es el algoritmo más eficiente, con complejidad O(log(n)) logra la mayor
velocidad.

Al observar los resultados de este último algoritmo observamos pequeñas
anomalías.
Así como en las mediciones con tiempos mas pequeños. Esto se debe al ruido del
sistema, así como imprecisiones con tiempos tan pequeños.

Sin embargo, en todos los casos, las mediciones, contrastados con las cotas
escogidas, corroboraron los resultados
